# Puck Legacy Launcher

This launcher will assist in the setup and download of Puck build 202, as well as the required plugin to make it actually work.

## Tutorial

1.) Download the latest branch as a zip. Then extract the zip where ever you want Puck Legacy to install to.  
2.) Run the OldPuckLauncher.exe and make sure Steam is open.  
3.) Click Setup Puck202, then select where you want it to install to. (Usually the same place you put the launcher)  
4.) After you select where to install it to, wait for Steam to do it's thing.  
5.) Once the launcher log reads that the depot is installed and moved to where you selected you can hit Play.  
  
Whenever you launch the game through the launcher, it will automatically check the github for plugin updates.  
  
Once in the game, you can set your name & number under Player > Identity.  
  
You can change this as much as you want, it will warn you that you can't change for another 7 days, but that's not true you can.
